# Pocket Circuit PRO-68K

A tiny circuit drift racing game for X680x0


---

## About This

ドリフトラジコン風のカーゲームです。サイバースティックに対応しています。

 <img src='pocketct1.jpg' width='800px'/>


アクセラレータ(060turbo/PhantomX)とハイメモリを搭載した環境では、全く同じコース・ルール・操作・物理演算のまま3Dビューで遊ぶことも可能です。

 <img src='pocketct3.jpg' width='800px'/>

なお、処理速度の関係で3D表示はインターレース(1ライン飛ばし)となっています。でもある隠しコマンドでフルスキャンも...?

---

## 動作環境(2Dモード)

* X68000/X68030実機
* サイバースティック または ジョイスティック(ポート1に接続のこと)

サイバースティックを使用する場合は、事前に標準ドライバの AJOY.X を常駐させてください。
X68000 LIBRARY などからダウンロード可能です。
- http://retropc.net/x68000/software/hardware/analog/ajoy/

060turboでAJOY.Xを使う場合は、HUYE氏のパッチを当ててください。
- http://park7.wakwak.com/~huye/x68000_joy.html


---

## 動作環境(3Dモード)

* X68030実機 + 060turbo

コピーバックモードを使用してください。(060turbo.sysに`-cm1`を指定)
ハイメモリが必須です。68060専用バイナリである`POCKETCT060.X`を使用してください。


* X68000実機 + PhantomX

Pi4B + ライトバックモードを使用してください。

はう氏のハイメモリドライバ TS16DRVp の登録が必要です。
- https://haumea.x68kbbs.com/

## 遊び方

ZIPアーカイブファイルを展開し、`POCKETCT.X`, `COURSE1.DAT`, `COURSE1.GRP`, `RAY128.LUT` がカレントディレクトリにあることを確認します。

サイバースティックを利用する場合は `AJOY.X` を常駐させます。

ゲームを起動すると、ハイメモリドライバの登録がされている場合は 3D VIEW か 2D VIEW かの選択になります。
レバーやパッド方向キーで選択し、ボタンを押すと決定になります。

<img src='pocketct4.jpg' width='600px'/>

コースデータのロードが終わると加速待ちの状態からスタートします。最初にスタートラインを切ったところからカウントが始まります。

基本的にタイムアタックをするゲームではなく、いかにドリフトを深いアングルかつロングストロークで、コースからはみ出さないようにして決め、ポイントを稼ぐのが目的です。

5ラップするとゴールでリザルトが表示されます。

<img src='pocketct2.jpg' width='800px'/>


ADPCM/FM音源とも使っておらず無音なので、お好きなドライブ・レースゲームのMDXなどを事前に鳴らしておいてからスタートするのがおすすめです。
